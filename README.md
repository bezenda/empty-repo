# empty-repo

This repository is a **blank canvas used for testing the capabilities of AI agents**.

It contains nothing but a Git repo and this README. The purpose is to give a future agent a clean workspace to perform actions — such as writing code, creating files, configuring tools, or running commands — without any pre-existing code, dependencies, or history to reason around.

Think of it as: "what would a capable agent do here?" The repo is intentionally empty so agent behavior, tooling, and problem-solving can be evaluated from scratch.
